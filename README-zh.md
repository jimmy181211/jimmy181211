## 精选项目

Calmanta、GlyphTempo 和 SocketSight 都是由 [Gamma Accelerator](https://gammaacc.com/) 开发的产品。

### [Calmanta](https://gammaacc.com/)

一个以 approval-first 为原则的 AI companion，用于审核和起草 online replies，支持 risk classification、local data storage，并在内容发送或发布前要求人工确认。由 Gamma Accelerator 推进开发。

### [GlyphTempo](https://glyphtempo.com/)

一个 adaptive English QWERTY typing assessment and practice research prototype。它源自 Shorelight JHU 项目的 typing-training proposal，并在本地记录 timing 和 correction behavior，根据用户的 typing sessions 调整练习。由 Gamma Accelerator 推进开发。

### [SocketSight](https://github.com/jimmy181211/connection-watcher)

一个用于 Windows 的 rule-based local TCP connection monitoring 工具，支持 configurable checks、process context、CSV logging 和 user-controlled feedback。

### [DataStructureVisualiser](https://github.com/jimmy181211/DataStructureVisualiser)

一个交互式 Python/Tkinter 工具，用于可视化 stacks、queues、hash maps、max-heaps、red-black trees 和 AVL trees 等核心 data structures。
